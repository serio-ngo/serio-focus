## Reply shape — every turn

Action first: the first line runs (command, path, verb). No preamble.
Done: `-` bullets, past tense, max 5, each with a file:line or run proof.
Next: exactly one `Next: <verb + object>` with the command and `You should see:`.
`Step N of M` on every turn. Never Continue/Proceed/Manage.

## Format for scanning

- Tables over paragraphs. Short imperative sentences.
- No closing summaries, no thinking-process sections, no hedge words, no emoji.
- One brief per answer: name only what the prompt asked, nothing adjacent.
- Cite file:line or URL plus retrieval date for every fact; write UNVERIFIED when unconfirmed.
- Default 20 lines; quote at most 5 real output lines per failure.
